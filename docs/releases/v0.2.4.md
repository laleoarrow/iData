## v0.2.4

### UI/UX Refinements
- **Unified Carousel Transitions**: Wrapped the welcome screen tutorial preview carousel in a single transitioning block with spring curves, eliminating conflicting animations and layout stutter.
- **Optimized Tutorial Coach**: Rewrote the active tutorial coach overlay to use a single spring animation and unified shadow. Removed redundant colored shadows and container hover scale modifiers, preventing layout thrashing and making tutorial navigation extremely fluid.
- **Aligned Hover Glows**: Aligned the sidebar recent file row hover glow corner radius to match the button background (12pt), resolving overlapping rounded borders.

### Navigation and macOS Integration
- **Horizontal Wheel Navigation**: Horizontal mouse wheels and trackpad left/right gestures now move across VisiData columns, matching the existing vertical scroll behavior for rows.
- **Menu Bar Access**: iData now shows a menu bar item by default, with quick actions for showing the main window, opening a file, preferences, update checks, and quit.
- **Optional Dock Hiding**: Added a preference to hide the Dock icon while keeping the menu bar item available so the app remains easy to reopen.
