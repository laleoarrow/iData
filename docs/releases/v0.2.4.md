## v0.2.4

### Product Experience
- Refined small-file handoff so common lightweight tables can open in the preferred external app, with WPS Office prioritized before Microsoft Excel when available.
- Added a returnable handoff notice for external opens, so users can bring a transferred file back into iData when needed.
- Polished the session header into a compact command area, grouping Open, Reopen, Finder, and Copy Path actions while giving the VisiData table more room.

### Interface Polish
- Unified the liquid-glass sidebar, settings panels, dropdown controls, and hover states for a calmer, more consistent interface.
- Reduced duplicate borders and mismatched corner radii around the embedded table, status panel, tutorial coach, and recent-file rows.
- Added subtle hover motion to circular controls such as Settings, Help, and input switching.
- Reworked Chinese interface copy to sound more natural and concise.

### Stability
- Improved recent-file hit targets in collapsed sidebar mode.
- Added tests for handoff behavior, compact layout, hover affordances, and terminal corner masking.
