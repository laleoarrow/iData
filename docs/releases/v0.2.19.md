## v0.2.19

这是一个并发稳定性修复版本，不改变现有 UI 与操作方式：

- 修复快速切换数据文件后，VisiData 仍在运行但表格偶尔空白的问题。
- 终端重置、输出与尺寸消息现在按显示代次隔离，旧消息不会再覆盖新表格。
- 修复旧视图误解绑新终端、Web 内容进程恢复后不重绘，以及旧 PTY 写入串入新会话的问题。
- 进程退出收尾统一回到主执行器，避免数据竞争和错误会话状态。
- “设置 → 文件 → 转交小文件”继续保留；关闭后，从 Finder 打开的小表格会直接留在 iData。
- 完整通过重复单元测试、AddressSanitizer、ThreadSanitizer，以及文件切换、重绘、焦点、缩放和进程退出压力测试。
