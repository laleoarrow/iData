## v0.2.7

### Performance and responsiveness

- Made sidebar collapse and expansion immediate by removing window-wide layout and sidebar-mode transition animations.
- Reduced unnecessary welcome-screen updates by isolating tutorial carousel state, keeping stable view identities, and publishing format-association state only when it changes.
- Coalesced PTY output into ordered batches of up to 64 KiB and simplified the Base64 terminal bridge, reducing native-to-WebKit handoffs during sustained output.
- Removed temporary-file probes from file-type lookup and stopped delimiter scanning after the first eight non-empty, non-comment lines.

### Reliability

- Added regression coverage for bounded, ordered terminal output; byte-safe bridge writes; file-type mapping; sidebar and welcome-screen recomputation safeguards; and delimiter detection.
- Updated install, file-handoff, compressed-input, and contributor performance-check documentation.
