## v0.2.5

### Sidebar and Navigation
- Added smoother, coordinated transitions when expanding or collapsing the sidebar.
- Centered the collapsed App icon as the single expand target and removed the overlapping chevron control.
- Made collapsed recent-file behavior predictable: clicking always opens the file, while Open, Pin, and Remove remain available from the context menu.
- Stabilized the sidebar footer and header controls across narrow and expanded layouts.

### Interface and Commands
- Replaced the nested runtime and update cards with one quieter, responsive System Status section that matches the rest of the welcome screen.
- Added native Open, Reopen, Session, Finder, Copy Path, Tutorial, and handoff commands with consistent keyboard shortcuts.
- Improved the Open dialog so it remembers the last useful folder and handles supported selections consistently.

### Reliability
- Improved terminal launch and redraw coordination to prevent blank or stale VisiData content after first open, focus changes, and rapid file switching.
- Expanded regression coverage for sidebar interactions, app commands, Open-dialog state, terminal measurement, and forced redraw behavior.

### Distribution
- Removed Finder metadata from ZIP archives, made checksum entries portable, and moved package/appcast staging files out of the repository.
